# seltts
seltts est une application permettant de sélectionner une zone de l'écran afin de lancer une synthèse vocale uniquement sur cette zone.
Seltts est compatible avec la loupe de Windows à condition que la sélection reste visible dans l'écran

Les raccourcis claviers permettant de lancer les différentes fonctions sont modifiables dans le fichier seltts.settings
Les raccourcis par défaut sont :
- "Ctrl+Alt+Shift+f" : lance la voix de synthèse française sur la zone capturée
- "Ctrl+Alt+Shift+a" : lance la voix de synthèse anglaise sur la zone capturée
- "Ctrl+Alt+Shift+e" : lance la voix de synthèse française et épelle la zone capturée
- "Ctrl+Alt+Shift+q" : quitte l'application

Pour fonctionner Seltts requiert l'application [tesseract-ocr](https://github.com/tesseract-ocr/tesseract/releases)
